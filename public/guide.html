Open the dashboard

  1. Install dependencies (once): in the project folder run npm install
  2. Configure API keys (optional but recommended): copy .env.example to .env and set at least OPENAI_API_KEY for chain photo analysis. Add REPLICATE_API_TOKEN for photo→photo edits. Set BLENDER_PATH if Blender is not in the default macOS location.
  3. Start the server: npm start (or node server.js)
  4. Open the app in your browser: http://localhost:3000 (if PORT is set in .env, use that port instead).
  5. Use the sidebar: Photo → AI → print to upload from files or camera, describe changes, then One-click: analyze + STL. Download STL from the top bar for slicing.
